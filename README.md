## Cómo usar esto

Cada carpeta trae su propio README con el contexto: qué se hizo en la clase,
qué archivos son y qué tiene que salir cuando corres el prompt. Los prompts
están en markdown para que los copies y los pegues tal cual.

**Todos los datos de este repo son inventados.** Las empresas, los RFC y las
facturas se armaron para dar clase. Nunca vas a encontrar aquí información de
un cliente real, ni mío ni de nadie.

## Lo que estos prompts sí hacen y lo que no

Los prompts **señalan, clasifican y priorizan.** Te dicen dónde mirar y en qué
orden. La conclusión fiscal y la firma siguen siendo tuyas: ninguna de estas
herramientas dictamina, y quien responde ante la autoridad eres tú.

Dicho de otro modo: esto te ahorra las horas de encontrar, no las de decidir.
